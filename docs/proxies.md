# 0xProxy: Подсистема Управления Прокси & Сетевой Маршрутизации

## 1. Назначение подсистемы
Подсистема **0xProxy** обеспечивает отказоустойчивую маршрутизацию внешних сетевых запросов платформы **0xAgent**, защищая локальный IP-адрес разработчика от блокировок, геоблоков и капч со стороны внешних провайдеров.

## 2. Матрица маршрутизации (Routing Matrix)

| Подсистема | Протоколы | Зачем требуется прокси |
| :--- | :--- | :--- |
| **Cloud AI & STT** (Groq Whisper, OpenAI, Anthropic) | HTTPS / SOCKS5 | Обход региональных блокировок Cloudflare (ошибки 403 Forbidden). |
| **Web Search & Scraping** (DuckDuckGo, SearXNG, Jina Reader) | HTTPS / SOCKS5 | Защита от банов по IP и капч при частых запросах фактчекера и поисковых агентов. |
| **Media & Downloaders** (yt-dlp, TikTok, YouTube Shorts, Reels) | HTTP / SOCKS5 | Загрузка субтитров и медиапотоков в обход региональных ограничений CDN. |
| **Локальные модели & LAN** (llama-server, DirectML Qwen3, LAN Nodes) | **Всегда Direct** | Локальный трафик на 127.0.0.1 никогда не идет через прокси ради нулевой задержки. |

## 3. Автоматическая ротация и мониторинг
- **Smart Auto-Rotation (`proxyService.getBestProxy()`):** Система автоматически выбирает из активных прокси тот, у которого минимальная задержка (ping).
- **Background Health Check:** Каждые 60 секунд фоновый таймер опрашивает ноды. Если прокси падает, статус меняется на `offline`, а трафик мгновенно переключается на запасной прокси.
- **Экспорт в один клик:** Возможность скопировать весь пул в форматах JSON, текстового списка или переменных `.env` (`HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY`).

## 4. Управление через интерфейс
Перейдите в веб-интерфейсе: **Настройки (Settings) → 0xProxy & Шлюзы**.
Вам доступны:
- Глобальный мастер-тумблер включения/выключения.
- Независимые переключатели для каждой категории трафика.
- Пакетный импорт прокси строками любого формата.
- Индивидуальное тестирование задержки каждого прокси.
