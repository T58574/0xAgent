# Справочник актуальных локальных LLM и оптимизации llama.cpp (Август 2026)

Комплексный отчет по открытым моделям для локального запуска в 0xAgent / `llama-server.exe` с расчетом VRAM, спецификациями квантований и бенчмарками скорости.

---

## 1. Спецификации ключевых семейств моделей (Август 2026)

### 1.1. Семейство Qwen (Alibaba Cloud)
*   **Qwen 3.8 Series** (Август 2026):
    *   `Qwen3.8-27B` (Dense) — флагманский локальный открытый релиз (август 2026). Архитектура нового поколения, расширенное контекстное окно до 128k, нативная поддержка агентского Tool Calling и глубоких рассуждений.
    *   `Qwen3.8-Max` (2.4T Sparse MoE) — облачный флагман через API.
*   **Qwen 2.5 Coder Series** (Золотой стандарт для кодинга и автономных агентов):
    *   `Qwen2.5-Coder-14B-Instruct` — абсолютный лидер в категории 14B для написания кода, отладки, выполнения `patch_file` и генерации JSON/XML инструментов.
    *   `Qwen2.5-Coder-7B-Instruct` — ультра-быстрая модель (50–70 tok/s) для интерактивного Tool-Loop и фоновых утилит.
    *   `Qwen2.5-Coder-32B-Instruct` — уровень GPT-4o в задачах архитектурного проектирования и рефакторинга.

### 1.2. Семейство Google Gemma (Google DeepMind)
*   **Gemma 4 Series** (Апрель 2026, лицензия Apache 2.0):
    *   `Gemma 4 31B` (Dense) — мультимодальная модель для сложных агентских цепочек и глубокой аналитики, контекст до 256K.
    *   `Gemma 4 26B` (MoE) — архитектура Mixture-of-Experts с высокой скоростью генерации и низким энергопотреблением.
    *   `Gemma 4 E4B / E2B` — компактные модели для легких задач и устройств периферии.
*   **Gemma 3 Series**:
    *   `Gemma 3 12B / 27B` — высокая эрудиция, поддержка 140+ языков, обработка изображений.
*   **Gemma 2 9B Instruct**:
    *   Оптимизированная рабочая лошадка с выдающимся качеством текста и логики на небольшом объеме VRAM.

### 1.3. Семейство DeepSeek (Reasoning & Distillations)
*   **DeepSeek-R1-Distill-Qwen-14B / 7B / 8B / 32B**:
    *   Дистилляции цепочки рассуждений (Chain-of-Thought, `<think>`) флагмана R1 в архитектуру Qwen.
    *   Выдающиеся результаты в математике, решении сложных алгоритмических задач и пошаговом планировании.
*   **DeepSeek-V3 / R1 (Full 671B MoE)**:
    *   Для локального запуска требует кластер из нескольких GPU (или CPU RAM от 400 ГБ+).

### 1.4. Семейство Microsoft Phi
*   **Phi-4 (14B)**:
    *   Компактная 14B модель с упором на синтетические датасеты высокого качества, алгоритмы и математику.

## 3. Таблица квантований GGUF и их влияние на точность

| Квантование | Бит / вес | Потеря качества (PPL) | Рекомендация к использованию |
| :--- | :--- | :--- | :--- |
| **`Q8_0`** | 8.5 bpw | Практически 0.0% | Рекомендуется для моделей **7B–9B** (помещаются целиком в 16GB). |
| **`Q5_K_M`** | 5.5 bpw | < 0.5% (незаметно) | Идеальный выбор для **14B** при умеренном контексте (16k–24k). |
| **`Q4_K_M`** | 4.5 bpw | ~ 1–1.5% | **Золотой стандарт** для **14B** (запас под контекст 32k/64k). |
| **`IQ4_XS / IQ4_NL`** | 4.25 bpw | ~ 1.5% | Экономия ~500 МБ VRAM по сравнению с Q4_K_M. |
| **`IQ3_M / IQ3_S`** | 3.3–3.5 bpw | ~ 3–5% | Для запуска **27B–32B** моделей в 16 ГБ VRAM без сброса в RAM. |
| **`Q2_K / IQ2_XXS`** | 2.0–2.5 bpw | Значительная (>10%) | Не рекомендуется для кодинга (возможны синтаксические ошибки). |

## 4. Оптимальные параметры запуска `llama-server.exe`

Для Windows + AMD Radeon RX 7800 XT (Vulkan) + Intel i5-14600KF:

```bash
llama-server.exe \
  -m models/Qwen2.5-Coder-14B-Instruct-Q4_K_M.gguf \
  --host 127.0.0.1 \
  --port 8080 \
  -ngl 99 \
  -fa on \
  -c 32768 \
  -ctk q8_0 \
  -ctv q8_0 \
  -b 2048 \
  -ub 512 \
  -np 1 \
  -t 6
```

### Ключевые флаги и их роль:
1. **`-ngl 99`** (*Number of GPU Layers*): полная выгрузка всех слоев модели в VRAM видеокарты.
2. **`-fa on`** (*Flash Attention*): обязательный флаг. Сокращает время обработки входящего промпта (Prompt Processing) в 2–3 раза и уменьшает потребление памяти кэша.
3. **`-ctk q8_0 -ctv q8_0`** (*Quantized KV Cache*): квантование контекстного кэша ключей и значений в 8 бит. Сохраняет 3–5 ГБ VRAM на контексте 32k без потери точности.
4. **`-np 1`** (*Parallel Slots*): 1 слот. По умолчанию `llama-server` резервирует 4 слота, что делит доступный VRAM и контекст на 4 части.
5. **`-t 6`** (*CPU Threads*): использование только 6 мощных Performance-ядер Intel Core i5-14600KF. Исключает лаги от медленных E-ядер.
6. **`-b 2048 -ub 512`** (*Batch & Micro-batch*): оптимизация параллельного вычисления промпта.
