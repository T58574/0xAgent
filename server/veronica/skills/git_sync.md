# Skill: Git Branch & Repository Sync

## Purpose
Ensure local git branches are up to date with origin and working trees are clean.

## Operational Instructions
1. Run `git status` to verify modified or untracked files.
2. Check for stashes or uncommitted changes.
3. If clean and authorized (L3+), pull latest upstream updates.
4. Report status to Veronica via `0xagent veronica report`.
