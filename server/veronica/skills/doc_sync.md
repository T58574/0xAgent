# Skill: Bilingual Documentation Synchronization

## Purpose
Synchronously maintain complete parity between English (`README.md`, docs) and Russian (`README.ru.md`, docs) user-facing documentation.

## Operational Instructions
1. Inspect recent feature additions, CLI flags, configuration schema changes, or UI updates.
2. Update `README.md` with accurate code blocks, tables, and instructions.
3. Update `README.ru.md` in strict 1-to-1 parity (same structure, tables, and code snippets).
4. Verify all internal file links (`[file](...)`) and anchors.
5. Report completion via `0xagent veronica report`.
